# Homebrew Git Town Dev                                                                   
                                                                                             
Homebrew tap for the `fork-stack` branch of [wmontwe/git-town](https://github.com/wmontwe/git-town).                                  
                                                                                             
## Installation                                                                           
                                                                                             
```sh                                                                                     
brew tap wmontwe/git-town-dev                                                             
brew install --HEAD wmontwe/git-town-dev/git-town-fork
```

## Updating

```sh
brew reinstall wmontwe/git-town-dev/git-town-fork
```
